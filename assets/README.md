# assets/

Place any static images (logo, screenshots for the main README, etc.) here.
No binary assets are bundled by default — add your own screenshots after
running the app locally, e.g.:

```
assets/
├── dashboard-screenshot.png
└── data-editor-screenshot.png
```

Then reference them in the root `README.md` with standard Markdown image
syntax: `![Dashboard](assets/dashboard-screenshot.png)`
